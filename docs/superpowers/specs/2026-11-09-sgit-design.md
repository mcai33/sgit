# sgit 设计

sgit 通过仓库现有的 Git 远端在设备间同步代码。设备各自登记本地工作树。独立 CLI 和 Tauri + Svelte 桌面端共享 Rust 核心与本机仓库清单。

- 添加时解析工作树根目录并去重。仓库清单只保存路径与显示用标识，使用系统 Git 的凭据和身份配置。
- 操作开始时读取当前分支的上游并获取远端分支。拉取允许快进，存在已跟踪文件的改动或 Git 操作尚未结束时停下。
- 推送前检查远端分支是本地 HEAD 的祖先。有改动时用 Git 自动提交已跟踪文件及用户显式暂存的新文件，再推送至上游分支。推送失败时显示已生成的提交。
- 两个入口使用同一进程间锁串行执行清单更新和同步。批量任务逐仓库执行并报告结果。
- 桌面端支持选目录、多选、查看变更及逐仓库结果。CLI 支持单仓库或全量操作。
