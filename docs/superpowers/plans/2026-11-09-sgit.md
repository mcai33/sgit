# sgit Implementation Plan

> **For agentic workers:** Implement in the current session with verification checkpoints.

**Goal** Ship a CLI and a desktop application for syncing existing Git worktrees.

**Architecture** The root Rust package provides the shared library and CLI. The desktop backend depends on the library and sends per-repository results through a Tauri channel.

**Tech stack** Rust, system Git, Tauri 2, Svelte, TypeScript.
